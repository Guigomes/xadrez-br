## Como o jogador se inscreve

Com o torneio no status "Inscrições abertas", o organizador compartilha o
link de inscrição (disponível na aba Inscrições do painel do torneio) com
os jogadores. Cada um preenche seus próprios dados e envia — a inscrição
entra como **pendente**, esperando aprovação do organizador.

Se o torneio exigir comprovante de pagamento, o formulário pede o upload de
um arquivo antes de enviar. Se exigir ID CBX, o campo é obrigatório no
formulário.

Rating não é pedido no formulário — só entra depois, se o organizador
preencher manualmente na aba Participantes (necessário só quando o torneio
usa classificação por rating).

## O que o organizador vê

Na aba Inscrições, as inscrições aparecem em três listas: Pendentes,
Aprovadas, Rejeitadas. Pra cada inscrição pendente, o organizador pode:

- **Aprovar**: o jogador entra oficialmente no torneio, num grupo de
  emparceiramento e numa classificação (calculados automaticamente pelos
  dados declarados — idade, rating, sexo).
- **Rejeitar**: com motivo opcional, visível pro jogador.

Se o dado que o jogador declarou não bate com o que o sistema calcularia
pra classificação (por exemplo, idade que colocaria ele noutra faixa), o
painel avisa a divergência antes da aprovação — o organizador decide se
corrige ou aprova como está.

## Inscrição depois do torneio já ter começado

Com o torneio "Em andamento", inscrições aprovadas ainda são aceitas — só
que como **entrada tardia**: o jogador recebe bye (0 pontos) nas rodadas já
disputadas do grupo dele, e joga normalmente a partir da próxima rodada.

## Encerramento

Inscrições podem ter uma data de encerramento configurada (o status muda
sozinho pra "Inscrições encerradas" quando ela chega) ou ser encerradas na
mão pelo organizador. Depois de encerradas, o formulário público para de
aceitar gente nova — reabrir é possível a qualquer momento clicando em
"Reabrir Inscrições".

## Cadastro manual

Quem não vai usar o link de inscrição também pode ser cadastrado direto
pelo organizador, na aba Participantes — "Cadastrar participante" pula o
fluxo de aprovação, mas exige grupo de emparceiramento igual a qualquer
outro jogador de torneio nativo.
